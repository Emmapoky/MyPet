# Demo voice log

`carl_voice_log.m4a` is a made-up voice message from "Carl", a demo owner, for the
"Log while driving" demo. The voice is synthetic: Kokoro TTS (voice am_michael), an
open-weight model under the Apache 2.0 licence, run offline. The road noise underneath is
generated (brown noise and a low engine hum). No real person's voice is used.

`carl_voice_log.json` lists when each sentence is spoken, so the demo shows the words
appear and the log fill in as they are said.
